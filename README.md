# ​ SHOPPINGAPP

A responsive, static e-commerce storefront built with **HTML**, **CSS**, and **JavaScript**, showcasing products in a clean and intuitive interface. Designed with simplicity and clarity in mind, this app brings a seamless shopping experience—even as a frontend-only project.

##  Live Demo

Check out the live version here:  
**[My Shop – Live Demo](https://shoppingapp-tan.vercel.app/)**

---

##  Features

-  **Homepage** and **Products** pages (navigation enabled).
-  **Responsive design** — adapts well to both desktop and mobile screens.
-  Clean, modern layout and user experience.
-  **Static structure** using vanilla HTML, CSS, and JavaScript (no backend).
-  Easily extensible for dynamic features like product details, cart, or user accounts.
